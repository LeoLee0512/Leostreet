## 与 0.2.0 的差异

- 架空大陆升级为「三国多省」大世界沙盘（2400×1500）：狮子国/大卫国/拉莫娜国共九个省 + 群岛；新增城市楼群、市中心、工厂烟囱、港口栈桥与泊船、黄铜金融高塔、方尖碑、灯塔、三条海上航线与商船。
- 练习场改为《维多利亚3》式左右翼板布局，菜单卡分列两侧，中间让给地图；练习场底图现在可以缩放（滚轮/捏合/缩放控件）。
- 建档页性别卡换装 3D 瓷偶人物：男士高顶礼帽三件套、女士酒红大摆礼服；象牙釉面+红晕+黄铜件。
- 主界面模式卡「剧情战役」更名「危机历史」。
- 修复：新闻正文不再使用首字下沉大写字母。
- 3D 画布全部带首帧预热，规避部分合成器丢首帧导致的空图。
